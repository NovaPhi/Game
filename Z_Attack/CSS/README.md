# CSS Section

This folder contains the stylesheets that give **Z_Attack** its visual identity. Each page of the game has its own dedicated CSS file.

## Structure

Each stylesheet targets a single page or feature, aligning with the project's page structure:

| File | Targets |
|------|--------|
| `main.css` | Main page |
| `game.css` | Game page |
| `cards.css` | Cards collection page |
| `cardsUnlock.css` | Card unlock animations |
| `LogIn.css` | Login page |
| `SignUp.css` | Sign-up page |
| `Admin.css` | Admin panel |
| `Settings.css` | Settings page |
| `UserStats.css` | User statistics page |
| `leaderboard.css` | Leaderboard page |
| `dataGraph.css` | Data graph view |
| `story.css` | Story page |
| `tutorial.css` | Tutorial page |
| `ColorblindChnge.css` | Colorblind mode adjustments |

## Use of AI

We used AI assistance for most of the styling in this folder, including:

- Targeting specific elements and crafting unique, page-appropriate styles.
- Generating the `@keyframes` animations used in files such as `cardsUnlock.css`.

## Why

As a team, we made the decision to rely on AI for a big part of the CSS work.  so that our time and focus could go where it mattered most: the **game logic**, **systems**, and **implementation**. This allowed us to use our time to focus mainly on development and not have to worry too much on styling.
